Anuphan and Mitr are bundled locally so builds do not fetch Google Fonts CSS
or use Turbopack's Google Fonts URL processing.

Sources: Google's official font repository:
- https://github.com/google/fonts/tree/main/ofl/anuphan
- https://github.com/google/fonts/tree/main/ofl/mitr

Downloaded November 9, 2026 and losslessly compressed from TTF to WOFF2 using
FontTools. Thai and Latin character mappings were verified after conversion.
The original SIL Open Font License files are included alongside the fonts.
