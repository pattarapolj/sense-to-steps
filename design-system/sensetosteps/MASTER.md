# Design System Master File

**Project:** SenseToSteps  
**Palette:** logo-derived soft pastels

## Colors

Extracted from `public/logo.png` / `public/logo_nobg.png`, then softened for full-page sections.

| Role | Hex | Logo source | Usage |
|------|-----|-------------|--------|
| Cream | `#FFF6E8` | Logo cream bg `#F8E8D0` | Page base, hero, reviews, team, footer |
| Soft blue | `#B8D9EC` | Logo blue `#0870B0` | Letter section, soft UI fills |
| Soft green | `#A8DBC4` | Logo green `#10A068` | Contact section, accents |
| Soft orange | `#FFD0A8` | Logo orange `#F87000` | Process section, hero CTA panel |
| Accent blue | `#0870B0` | Logo blue (exact) | CTAs, badges, focus rings |
| Accent hover | `#065F96` | Darkened accent | Button hover |

Text ink `#1F1714` for readability.  
Line green only on LineOA buttons.

## Logos

| File | Use |
|------|-----|
| `/logo_nobg.png` | Header, hero, footer (transparent) |
| `/logo.png` | Favicon / apple icon, solid cream bg |

## Hero media

`/hero.mp4` covers the **entire hero section** (full-bleed, edge-to-edge).  
`/hero-poster.jpg` is the poster + reduced-motion fallback.  
Soft blue→cream brand wash over the video for text readability.  
Do not inset the video in a rounded panel.

## Section rhythm
1. Cream — Hero  
2. Soft blue — Letter  
3. Cream — Reviews carousel (slides use all 4 pastels)  
4. Soft orange — Process  
5. Cream — Team  
6. Soft green — Contact
